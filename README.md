# Corporate Finance & Operations Dashboard

A Tableau dashboard designed to analyze corporate financial and operational performance using a structured financial dataset.

## Tools & Technologies

- Tableau
- SQL
- Microsoft Excel
- Calculated Fields
- Data Cleaning
- Data Visualization

## Dashboard Features

- Total Revenue
- Total Expense
- Total Profit
- Profit Margin
- Total Customers
- Revenue vs Expense Trend
- Profit by Region
- Revenue by Department
- Revenue by Product Category
- Profit Heatmap

## Key Insights

The dashboard provides an interactive view of revenue, expenses, profitability, customer volume, regional performance, departmental contribution, and product-category revenue.

## Files

- `Corporate_Finance_Operations_Dashboard.twb` - Tableau workbook
- `finance_operations.csv` - Dataset used for analysis
